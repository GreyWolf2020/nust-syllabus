% COURSE SYNOPSIS
\subsection*{Course Synopsis}
The module focuses on semiconductors materials i.e.\ atomic theory and band-gap.
It also focuses on the p-n junction characteristics i.e.\ field theory, electric and magnetic fields.
\vspace{2ex} \hrule\vspace{2ex}
% ----------------------------------------------------- %
% COURSE TOPICS
\subsection*{Topics}
\begin{outline}
    \1 Classification Engineering Materials
    \1 Conductors
    \begin{itemize}
        \item The Structure of an atom
        \item Atomic Arrangement
        \item Electrical Conductivity
        \item Band Theory and Temperature effects
        \item Applications
    \end{itemize}
    \1 Semiconductors
    \begin{itemize}
        \item Energy Gaps
        \item Intrinsic Semiconductors
        \item Extrinsic Semiconductors
        \item Contact Phenomenon i.e\. P-N Junction and Contact Metal-semiconductor
        \item Applications
    \end{itemize}
    \1 Dielectric Material
    \begin{itemize}
        \item Polarisation
        \item Dielectric constant
        \item Dielectric Strength
        \item Frequency and Effects of Temperature
    \end{itemize}
    \1 Magnetic Material
    \begin{itemize}
        \item Magnetic Dipoles and Magnetic Moments
        \item Magnetisation and permeability
        \item Interactions between Magnetic Dipoles and Magnetic Field
        \item Domain Structure
        \item Applications
    \end{itemize}
\end{outline}
