% COURSE SYNOPSIS
\subsection*{Course Synopsis}
This course delves into design and performance analysis of communication circuits i.e.\ tuned amplifiers, impedance matching, oscillators, filters, transmission lines and phase locked loops.
Then it covers some application examples of the circuits.
\vspace{2ex}\hrule\vspace{2ex}

% ----------------------------------------------------- %
% COURSE TOPICS
\subsection*{Topics}
\begin{outline}
    \1 The concepts of Noise Characterisation and Receiver Performance
    \1 Overview of Contemporary Communication Systems Link Budgets
    \1 Introduction to Random processes and Spectral Analysis
    \1 Random processes and Spectral analysis
    \begin{itemize}
        \item  Linear Systems
        \item Bandwidth Measurement
        \item The Gaussian Random Process
        \item Bandpass Processes
        \item  Matched filters
    \end{itemize}
    \1 Performance of Communication Systems Corrupted by Noise Error Probabilities for Binary Signalling
    \1 Performance of Communication Systems Corrupted by Noise
    \begin{itemize}
        \item  Performance of Baseband Binary Systems
        \item Detection of Bandpass Binary Signals
        \item Comparison of Digital Signalling Systems
    \end{itemize}
\end{outline}
